# Scope and verification

An ACTIVE account's error-count backoff alone does not authorize abandoning a hard continuity owner. A resolved file, response, turn-state, or bridge owner has no interchangeable sibling. Admission retains runtime backoff counters so unrelated selection still avoids the account.

This is not permission to bypass account assignment or security authorization, persisted PAUSED/DEACTIVATED status, unrecovered rate/quota limits, known expired reauthentication, explicit cooldown, actual retry exclusions, or concurrency admission. Reservations and deferred account-health effects retain their existing ordering.

The original CI lint job failed before Ruff in migration topology. Its unit failures share the forked SCIM-token/subscription-overflow graph. Reproduction uses exact source snapshots, and candidate verification exercises the existing topology repair already present in the packet base, commit 09a140fa9. Historical migrations are not rewritten by this lane.
